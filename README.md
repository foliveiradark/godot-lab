# 🎮 Godot Lab

Laboratório de aprendizagem prática em desenvolvimento de jogos utilizando **Godot Engine** e **GDScript**.

## 🎯 Objetivo

O Godot Lab é um ambiente experimental criado para explorar, de forma prática e incremental, os fundamentos do desenvolvimento de jogos 2D.

O projeto busca compreender não apenas **como utilizar os recursos de uma game engine**, mas também **por que eles funcionam, quais problemas resolvem e como se relacionam com conceitos de programação e engenharia de software**.

## 🧠 Abordagem de aprendizagem

O aprendizado será conduzido por meio de pequenos experimentos, nos quais cada etapa parte de um conceito, passa pela implementação prática e registra os problemas e descobertas encontrados durante o processo.

A proposta é evoluir de:

**conceito → experimento → investigação → compreensão → aplicação**

O projeto também servirá como uma oportunidade para relacionar conceitos estudados anteriormente em programação, especialmente **Java e Programação Orientada a Objetos**, com problemas encontrados no desenvolvimento de jogos.

## 🧪 O que será explorado

A trilha inicial abordará progressivamente:

* fundamentos da Godot Engine;
* Scenes e Nodes;
* GDScript;
* entrada do jogador;
* movimentação;
* física;
* colisões;
* animação;
* câmera;
* inimigos e comportamentos;
* interação entre objetos;
* eventos e Signals;
* organização e arquitetura de pequenos jogos;
* criação de um pequeno jogo 2D.

## 🚧 Status

**Em preparação — Etapa 2: estruturação do projeto**

O projeto ainda não possui uma implementação de jogo. A primeira fase está concentrada na preparação do ambiente, definição da metodologia de aprendizagem e configuração das ferramentas.

## 📌 Escopo

O Godot Lab **não pretende ser um curso completo de Godot** nem uma tentativa de dominar todos os recursos da engine.

Seu objetivo é construir uma base prática suficiente para compreender os principais fundamentos do desenvolvimento de jogos e aplicá-los posteriormente em projetos reais.
