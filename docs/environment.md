# Development Environment

Registro do ambiente utilizado no desenvolvimento e experimentação do Godot Lab.

## Operating System

* **OS:** Linux Mint 21.3
* **Codename:** Virginia
* **Architecture:** x86_64
* **Session:** X11

## Hardware

* **GPU:** Intel HD Graphics 620 (KBL GT2)

## Graphics Stack

* **Graphics API:** OpenGL 4.6
* **Driver:** Mesa 23.2.1
* **Renderer:** Compatibility

## Development Tools

* **Game Engine:** Godot 4.7.1
* **Distribution:** Standard
* **Programming Language:** GDScript
* **Version Control:** Git
* **Repository Hosting:** GitHub

## Validação

A Godot Engine foi executada com sucesso utilizando a distribuição oficial para Linux x86_64.

Durante a inicialização, a engine identificou corretamente a GPU Intel HD Graphics 620 e iniciou utilizando o renderer **Compatibility**, com **OpenGL 4.6** através do **Mesa**.

**Ambiente validado com sucesso.**
